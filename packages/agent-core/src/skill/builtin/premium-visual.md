# Premium Visual (SuperLiora harness)

This skill is the relocated T2-2 craft block. Treat every section as a hard constraint, not inspiration.

## Composition anti-slop (operator defaults)

- Full-bleed hero as the dominant first viewport plane — not inset media cards, side panels, or floating image stacks.
- First viewport budget: brand, one headline, one short support line, one CTA group, one dominant visual. No stat strips, schedule blocks, or promo clusters above the fold.
- No hero overlays: no floating badges, promo stickers, or detached chips on hero media.
- Cards only when they contain a real interaction; never card-as-hero.
- Ban default AI clusters unless the brief explicitly requests them: purple-on-white / purple-indigo gradients; warm cream (~#F4F1EA) + terracotta serif; broadsheet hairline zero-radius newspaper columns.
- Avoid defaulting to dark-mode+glow, rounded-full pill forests, multi-layer shadow stacks, or emoji-as-UI.
