Add a power-user command palette to the TUI. The Command Hub (Ctrl-Space / Ctrl-K / `?`) now offers Help → Command palette: a fuzzy-search omnibox that runs any slash command, skill, or session action (Hub, shortcuts, transcript search, input history) directly. Search matches command aliases, and recently run entries float to the top through the existing Hub recency scoring; Esc returns to the Hub.
